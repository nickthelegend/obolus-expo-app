## 1. Project Overview
Obolus is a privacy-first mobile financial orchestrator built on Solana (via AppKit/Wagmi) that enables shielded inflows, instant advances, and automated bill payments. The mobile app serves as the primary touchpoint for UAE expats, students, and gig workers to manage their PUSD liquidity and interact with the Obolus AI assistant.

### Core Tech Stack
- **Framework:** Expo (React Native) + Expo Router (File-based routing)
- **Styling:** StyleSheet (Vanilla) with a custom design system (`constants/Colors.ts`)
- **Wallet/Web3:** Reown AppKit + Solana Adapter (Solana Only)
- **AI Engine:** Groq (Llama 3.3 70B) for natural language financial orchestration
- **Animations:** React Native Reanimated + Lucide/Ionicons
- **Data Fetching:** TanStack Query (React Query)

- **Intent Recognition:** Supports `SWAP`, `SEND`, `PORTFOLIO_VIEW`, and `PRICE_CHECK`.

## 5. Security & Privacy
- **TEE Ready:** Designed to interface with MagicBlock Private Ephemeral Rollups on Solana for confidential compute.
